# さくらんぼ けいさん（MieeL）

くりあがりの たしざん・くりさがりの ひきざんに とくかした さんすうの アプリです（特別支援教育向け・iPad / iPhone）。「10の まとまり」を、10の わくで いしを うごかして からだで おぼえ、さくらんぼ けいさんで しきに します。

## ステージ（19）
- 🔟 **10の しま**：10の ともだち（え・すうじ）／10と いくつ／さくらんぼで わけよう
- 🍒 **くりあがりの しま**：9 たす いくつ／8 たす いくつ／7・6 たす いくつ（いしを タッチで うごかして 10を つくる）／さくらんぼで たしざん（①あと いくつで 10？ ②のこりは？ ③10と いくつ）／ちいさい ＋ おおきい（3＋9）／くりあがりの たしざん
- 🍎 **くりさがりの しま**：10から ひこう／1□ ひく 9／1□ ひく 8・7（10の まとまりから タッチで とる）／さくらんぼで ひきざん（げんかほう）／すこしずつ ひこう（げんげんほう）／くりさがりの ひきざん
- 🏆 **チャンピオンの しま**：たしざん・ひきざん まぜて／おはなし もんだい（しきを えらぶ → こたえ）／スピード チャレンジ（じこベスト）

## くふう
- まちがえても ばつ なし：その ばで 10の わくで「やりかた」を みせて、もう いちど えらぶ。「💡 やりかたを みる」ボタンも いつでも つかえる
- こたえかた：えらぶ（2〜4こ）／すうじを うつ（テンキー）。タッチが むずかしい 子は いしの いどうを じどうに できる
- きろく：たしざん 36しき・ひきざん 36しき の せいかいりつを 表で（にがてが ひとめで わかる）、「🎯 にがてを れんしゅう」、CSV
- A4 プリント 9しゅるい（こたえ つき）：10の ともだち／10と いくつ／さくらんぼ たしざん・ひきざん／10の わくで たしざん／くりあがり・くりさがり 20もん／まぜて／にがての しき
- 「やすみの しゅくだい メーカー」から プリントを とりこめます（MieelPrintAPI）
